# Notepad

Open-source Android notepad app, built with Kotlin.

**Your thoughts, beautifully kept.**

## Features
- Create and edit notes and checklists
- Organize notes in folders
- Pin important notes
- Archive and trash
- Locked notes
- Search
- Simple, fast and clean design

## Build
1. Open the project in Android Studio.
2. Let Gradle sync.
3. Run on a device or emulator.
